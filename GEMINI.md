# Project: Checkmate

## Task Todo / Groceries Checklist
A simple to-do or grocery checklist app from a passive list-keeper, but turn it into an intelligent assistant.

## Function Examples
 - **AI Auto-Breakdown**: Write down all things you need, then AI auto breaks down into tasks or checklist items.
 - **Recipe Integration**: Paste a recipe link, and the AI automatically extracts ingredients and adds them to your shopping list.
 - **Auto-Categorization**: Automatically groups items by aisle (Produce, Dairy, etc.) for efficient shopping.
 - **Voice-to-List**: Natural language voice input to add multiple items at once.
 - **Meal Plan to List**: Generate a weekly meal plan and shopping list from a single prompt (e.g., "healthy dinners for two").

## Platform
 - Web App (Vite + React)

## Tech Stack
 - **Framework**: Vite + React
 - **Styling**: Plain CSS
 - **AI**: Gemini API
 - **Storage**: LocalStorage
